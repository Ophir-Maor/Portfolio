# Portfolio v2

- Use npm and commit package-lock.json with dependency changes.
- React + TypeScript + Vite, with Tailwind CSS through its Vite plugin.
- Keep TypeScript strict and dependencies minimal.
- Application composition lives in src/app; pages in src/pages; styles in src/styles.
- Add feature and reusable component directories when needed.
- Run npm run check and npm run build before committing changes.
- Never commit environment files or secrets.
- GitHub Pages is the eventual host; do not add backend services without a concrete requirement.
